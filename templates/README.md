## front-enjoy-polka

https://github.com/Lor-Web/front-enjoy-polka

Должен быть Template repository. В корне уже каркас Vite (`react`, JavaScript)
без алиаса и без ESLint — это домашнее задание. Ученик пишет свой README;
проверки лежат в `fe-checks/module-N.mjs`, запуск — `fe-checks/run.mjs` по
ветке `module_N`. Копии учеников платформа создаёт публичными.
