# Полка: React-приложение с нуля

Документация `/docs/react` — справочник (JSX, пропсы, списки). Курс — как уверенно собирать приложение: Vite, папки, линтер, компоненты, состояние, главные хуки, базовая мемоизация, роутинг. Стек курса: **React + JavaScript**, без TypeScript.

**Результат:** SPA «Полка» — учёт домашних книг. Первый модуль Полку на экран не выносит: сначала мастерская. Без видео. Раздел — документация: как устроена штука. Домашняя работа — только в последнем разделе модуля. Дальше — только после текущего.

## Модули

1. **Мастерская: Vite и линтеры**  
   Node, проект на Vite, карта папок, ESLint.

2. **Компоненты**  
   Как резать экран, композиция, пропсы. Шаблон Vite перестаёт быть заставкой.

3. **Состояние**  
   Где жить данным, обновления без мутаций, почему у карточки нет своего списка.

4. **Главные хуки**  
   useState, useEffect, useRef, свой хук — привычки, не коллекция API.

5. **Мемоизация без фанатизма**  
   memo, useMemo, useCallback и когда они только шумят.

6. **Роутинг**  
   Несколько экранов без перезагрузки.

## Модуль 1. Мастерская: Vite и линтеры

Цель: на компьютере запускается свой React-проект на JavaScript, понятно что в какой папке, линтер орёт в терминале и в редакторе. Карточку книги не рисуем.

Линтер в курсе — ESLint, как в шаблоне Vite (Biome на платформе — та же идея, другой инструмент). Команды в текстах — npm; pnpm/yarn можно, не смешивать в одном проекте.
