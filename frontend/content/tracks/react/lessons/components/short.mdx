Мы решили собирать меню «Зёрнышка» из кусков. Кусок в React — **компонент**: функция, которая возвращает разметку.

## Функция вместо шаблона

Имя пишут с заглавной буквы. Так React отличает `<Header />` от обычного `<header>`.

```jsx
function Header() {
  return <h1>Кафе «Зёрнышко»</h1>;
}
```

`Header` можно вызвать как тег внутри другой функции. Это не строка и не отдельный HTML-файл — это JavaScript, который описывает кусок экрана.

## Собираем каркас кафе

Корневой компонент приложения — `CafeApp`. Он пока ничего не знает про цены и заказ: только раскладывает экран на части.

```jsx
function Header() {
  return <h1>Кафе «Зёрнышко»</h1>;
}

function Menu() {
  return <p>Скоро здесь появятся напитки</p>;
}

function CafeApp() {
  return (
    <div>
      <Header />
      <Menu />
    </div>
  );
}
```

Точка входа по-прежнему одна:

```jsx
createRoot(document.getElementById("root")).render(<CafeApp />);
```

`CafeApp` рисует `Header` и `Menu`. Если шапку нужно поменять, правите одну функцию — меню не трогаете.

## Вложенность

Компоненты вкладывают друг в друга сколько угодно глубоко. Карточка напитка позже поселится внутри `Menu`:

```jsx
function DrinkCard() {
  return <article>Латте</article>;
}

function Menu() {
  return (
    <section>
      <h2>Меню</h2>
      <DrinkCard />
    </section>
  );
}
```

Держите компонент узким: одна задача, понятное имя. `Header` не считает заказ. `DrinkCard` не рисует всю страницу. Если функция разрослась — вынесите кусок в новый компонент.

## Что запомнить

- Компонент — функция с именем в `PascalCase`.
- Его вставляют как тег: `<Header />`.
- Экран — дерево маленьких компонентов, не одна огромная функция.
- У «Зёрнышка» корень — `CafeApp`, внутри — шапка и меню.
