React-приложение собирается из **компонентов** — функций, которые возвращают разметку. Один компонент описывает кусок интерфейса: кнопку, карточку, страницу.

## Функция вместо шаблона

Компонент — обычная функция JavaScript. Имя пишут с заглавной буквы, чтобы React отличил его от HTML-тега.

```jsx
function Welcome() {
  return <h1>Привет</h1>;
}
```

`Welcome` можно вставить в другой компонент так же, как тег: `<Welcome />`. Так из маленьких частей складывается экран.

## Вложенность

Компоненты вкладывают друг в друга. Страница урока может состоять из шапки, статьи и квиза — каждый кусок живёт отдельно и переиспользуется.

```jsx
function LessonPage() {
  return (
    <section>
      <Header />
      <Article />
      <QuizLink />
    </section>
  );
}
```

Держите компонент узким: одна задача, понятное имя. Если функция разрослась, вынесите кусок в новый компонент.

## Что запомнить

- Компонент — функция с именем `PascalCase`.
- Он возвращает JSX: описание того, что должно быть на экране.
- Сложный экран — дерево маленьких компонентов, а не одна огромная функция.
