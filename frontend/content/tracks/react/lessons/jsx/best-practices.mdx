JSX легко превратить в кашу. Правила ниже удерживают его коротким.

## Выражения, не рассказы

В `{ }` — короткое выражение. Цепочка из трёх тернарных операторов не принадлежит JSX: посчитайте `status` выше.

```jsx
// Лучше
const status = passed ? "сдан" : read ? "прочитано" : "не начат";
return <span>{status}</span>;
```

## Ключи и списки — не здесь

`key` ставят в `map`, не на внутренний элемент «на всякий случай». Подробности — в уроке про списки.

## Комментарии

В JSX комментарий такой: `{/* текст */}`. HTML-комментарий `<!-- -->` внутри компонента не работает.

## Безопасность

React экранирует текст в JSX. Не вставляйте HTML через `dangerouslySetInnerHTML`, пока нет явной санитизации. Для уроков и квизов этого достаточно: контент свой, не из произвольного ввода пользователя.
