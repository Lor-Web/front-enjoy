Читаемый JSX экономит больше времени, чем «умный» однострочник. Карточка латте должна сканироваться глазом за секунду.

## Фрагмент вместо пустого div

Не оборачивайте соседей в `<div>`, если обёртка не нужна для стиля или семантики. Лишние уровни ломают flex/grid: «почему карточка не в ряд» часто начинается с анонимного div вокруг всего.

`<>…</>` — нормальный корень `return`.

## Выносите сложные выражения

```jsx
function DrinkCard() {
  const priceLabel = `${drink.price} ₽`;
  const title = drink.name;

  return (
    <article className="card">
      <h3 className="card-title">{title}</h3>
      <p className="card-price">{priceLabel}</p>
    </article>
  );
}
```

Тернарник на три этажа внутри атрибута никто не отладит. Переменная над `return` — не «лишняя», а документация.

## Классы, не простыня style

Для кафе заведите CSS (или CSS-модули, когда понадобится). `style={{ marginTop: 8, marginLeft: 8, … }}` копирует дизайн в JS и мешает теме.

`style` оправдан, когда значение **считается**: ширина по проценту остатка, цвет из данных. Не когда вы верстаете карточку.

## Никакого innerHTML без нужды

```jsx
<article dangerouslySetInnerHTML={{ __html: drink.description }} />
```

Это дыра, если описание пришло от пользователя. React специально сделал имя страшным. Для «Зёрнышка» тексты — обычный `{drink.name}`. Markdown/HTML из CMS — только после санитайзера, не «потом».

Обычный `{userInput}` безопаснее: это текст, не разметка.

## Не пишите HTML-привычки

- `class=` → `className`
- `onclick=` → `onClick={fn}`
- незакрытый `<img>`
- несколько корней без фрагмента
- запятые между JSX-соседями, как в массиве объектов

Линтер с плагином React ловит половину. Включите его в реальном проекте; в учебном шаблоне смотрите на это глазами.

## Явные пропсы важнее spread

`{...props}` на своей карточке прячет контракт: какие поля обязательны, что уедет в DOM. Пока напиток — `name` и `price`, перечислите их. Spread нативный на `<button {...rest} />` — да, когда вы делаете обёртку кнопки.

## Форматируйте разметку

Длинный `return` в одну строку не доказывает крутость. Один проп — одна строка, дети с отступом, закрывающий тег на своём уровне. Так в диффе PR видно, что изменилось: цена или бейдж.

## Что запомнить

- Фрагменты и переменные делают JSX плоским и понятным.
- CSS-классы для вёрстки, `style` для вычисленных значений.
- Не вставляйте HTML строкой.
- Пишите JSX как JS, не как скопированный index.html.
