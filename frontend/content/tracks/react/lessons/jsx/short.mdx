JSX выглядит как HTML внутри JavaScript. Это не строка и не шаблонный язык: сборщик превращает JSX в вызовы функций React.

## Разметка рядом с логикой

В одном файле можно посчитать данные и сразу показать их в разметке:

```jsx
function LessonHeading() {
  const count = 2;
  return <h1>{count} урока в треке</h1>;
}
```

Фигурные скобки `{ }` вставляют любое JavaScript-выражение: переменную, вызов функции, тернарный оператор.

## Правила JSX

- Узел должен иметь **один корень**. Несколько соседних тегов оборачивают в `<></>` (фрагмент) или в `div`.
- Атрибуты пишут в camelCase: `className`, `htmlFor`, `onClick`.
- Самозакрывающиеся теги обязательны: `<img />`, `<Welcome />`.

```jsx
function Card() {
  return (
    <>
      <h2 className="title">JSX</h2>
      <p>Разметка в JavaScript</p>
    </>
  );
}
```

## Зачем это нужно

JSX держит разметку рядом с логикой того же компонента. Не нужно искать шаблон в другом файле, чтобы понять, что рисует функция.
