Каркас кафе уже есть: `CafeApp` → `Header` + `Menu`. Пора нарисовать настоящую карточку напитка. Разметка в React пишется **JSX**: это HTML-подобный синтаксис внутри JavaScript.

## Разметка рядом с логикой

Сборщик превращает JSX в вызовы функций React. Для нас это выглядит так:

```jsx
function DrinkCard() {
  return (
    <article>
      <h3>Латте</h3>
      <p>280 ₽</p>
    </article>
  );
}
```

Это не строка и не шаблон Handlebars. Рядом можно объявить переменную и сразу показать её на экране.

## Правила JSX

Несколько соседних тегов нельзя вернуть «россыпью». Нужен **один корень**: общий тег или фрагмент `<>...</>`.

```jsx
function DrinkCard() {
  return (
    <>
      <h3>Латте</h3>
      <p>280 ₽</p>
    </>
  );
}
```

Ещё три правила, о которые чаще всего спотыкаются:

- Атрибуты — **camelCase**: `className`, `htmlFor`, `onClick`. Слово `class` в JavaScript уже занято.
- Теги вроде `<img>` и компоненты закрывают сразу: `<img alt="Латте" />`, `<DrinkCard />`.
- Внутрь фигурных скобок кладут **выражение** JavaScript, не инструкцию `if`.

## Стили через className

CSS подключают как обычно. В разметке класс пишут так:

```jsx
function DrinkCard() {
  return (
    <article className="card">
      <h3 className="card-title">Латте</h3>
      <p className="card-price">280 ₽</p>
    </article>
  );
}
```

В таблице стилей это тот же `.card`, что и в HTML. Меняется только имя атрибута.

## Данные в фигурных скобках

Жёстко прошитые «Латте» и «280» неудобны: скоро у нас будет много напитков. Положим данные в объект и вставим в разметку:

```jsx
function DrinkCard() {
  const drink = {
    name: "Латте",
    price: 280,
  };

  return (
    <article className="card">
      <h3 className="card-title">{drink.name}</h3>
      <p className="card-price">{drink.price} ₽</p>
    </article>
  );
}
```

`{drink.name}` читается так: «выйди в JavaScript, возьми значение, покажи его». Сюда же можно поставить выражение: `{drink.price * 2}` — цена за два стакана.

Соберём карточку в меню:

```jsx
function Menu() {
  return (
    <section>
      <h2>Меню</h2>
      <DrinkCard />
    </section>
  );
}
```

Пока карточка знает только про один латте — данные живут внутри неё. В следующем уроке научим `CafeApp` передавать имя и цену снаружи.

## Что запомнить

- JSX — разметка в JavaScript, не HTML-файл.
- Один корень: тег или `<>...</>`.
- Классы — `className`, значения из JS — в `{ }`.
- Карточка «Зёрнышка» уже показывает объект `drink`.
