Три напитка мы уже рисуем тремя тегами. Добавить раф — значит копировать ещё строку. Меню кафе — это **массив**. React не умеет `for` внутри JSX, зато умеет `map`.

## Данные отдельно, карточки — из данных

```jsx
const drinks = [
  { id: "espresso", name: "Эспрессо", price: 180, isHit: false, inStock: true },
  { id: "latte", name: "Латте", price: 280, isHit: true, inStock: true },
  { id: "cocoa", name: "Какао", price: 240, isHit: false, inStock: false },
];
```

`id` — устойчивый идентификатор из данных, не номер по порядку. Если какао уберут из меню, латте не должен «стать» какао.

## map превращает массив в разметку

```jsx
function Menu() {
  const cards = drinks.map((drink) => (
    <DrinkCard
      key={drink.id}
      name={drink.name}
      price={drink.price}
      isHit={drink.isHit}
      inStock={drink.inStock}
    />
  ));

  return (
    <section>
      <h2>Меню</h2>
      {cards}
    </section>
  );
}
```

`map` для каждого элемента возвращает компонент. Массив компонентов можно вставить в JSX как `{cards}`. Часто `map` пишут сразу в `return`:

```jsx
function Menu() {
  return (
    <section>
      <h2>Меню</h2>
      {drinks.map((drink) => (
        <DrinkCard
          key={drink.id}
          name={drink.name}
          price={drink.price}
          isHit={drink.isHit}
          inStock={drink.inStock}
        />
      ))}
    </section>
  );
}
```

`DrinkCard` мы не трогаем: он по-прежнему рисует одну карточку по пропсам. Изменился только родитель.

## Зачем key

`key` — подсказка React: «этот элемент тот же, что был, только сдвинулся». Без ключей при удалении из середины списка React может перепутать карточки и оставить бейдж «Хит» не на том напитке.

- Хорошо: `key={drink.id}` — id из данных.
- Плохо: `key={index}` как постоянное решение. Индекс меняется, если массив переставить.
- Нельзя: одинаковые ключи у соседей.

Ключ передают тому элементу, который возвращает `map`. Это не проп для `DrinkCard` в обычном смысле: React снимает `key` до вызова функции.

Теперь меню растёт вместе с массивом. Добавили объект в `drinks` — появилась карточка. Кнопка «В заказ» пока ничего не делает. Следующий урок — события.

## Что запомнить

- Список рисуют из массива через `map`.
- У каждого элемента нужен устойчивый `key`.
- Карточка не знает про весь список — только про свои пропсы.
- Меню «Зёрнышка» больше не копирует теги вручную.
