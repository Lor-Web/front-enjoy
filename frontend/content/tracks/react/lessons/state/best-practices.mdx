Состояние легко размазать по дереву и начать править массивы на месте. В кафе это выглядит как «счётчик живёт своей жизнью».

## Не мутируйте то, что вернул useState

```jsx
function handleAdd(name) {
  order.push(name);
  setOrder(order);
}
```

Ссылка старая — экран может не обновиться, а данные уже испорчены. Всегда новый массив или объект:

```jsx
function handleAdd(name) {
  setOrder((current) => [...current, name]);
}
```

Для счётчика не пишите `count++`. Только `setCount`.

## От предыдущего значения — функция

Два быстрых клика, обработчик в `setTimeout`, несколько `set` подряд — берите апдейтер:

```jsx
setOrderCount((current) => current + 1);
```

`setOrderCount(orderCount + 1)` нормален, когда в этом обработчике одно обновление и вы уверены в свежем снимке. В `CafeApp.handleAdd` апдейтер безопаснее навсегда.

## Не копируйте пропсы в state «на всякий случай»

```jsx
function DrinkCard({ price }) {
  const [localPrice, setLocalPrice] = useState(price);
  return <p>{localPrice} ₽</p>;
}
```

Родитель поменял цену — карточка показывает старую. Либо читайте `price` как проп, либо это **местное** состояние со своей историей, и тогда проп — только начальное значение, которое вы сознательно игнорируете дальше. Второе редко нужно в меню.

## Считайте, не храните

```jsx
const [order, setOrder] = useState([]);
const [orderCount, setOrderCount] = useState(0);
```

Два факта про одно. Оставьте массив, `order.length` покажите в `OrderBar`. Сумму в рублях тоже считают из позиций, не держат третьим `useState`.

## Поднимайте только общее

Подсказка «что в латте» на одной карточке — `useState` внутри `DrinkCard`. Число позиций в заказе, которое видит вся страница — `CafeApp`.

Не тащите фокус инпута и открытие подсказки наверх «чтобы всё было в одном месте». Корень распухнет, лишние рендеры появятся раньше, чем вы дойдёте до мемоизации.

## Один факт — одно состояние

«Кафе открыто» и «в заказе 3» не обязаны быть полями одного объекта. «Состав заказа» — да, один массив. Не делайте `useState` на каждый напиток в заказе (`latteCount`, `cocoaCount`), если это один список позиций.

## Что запомнить

- Новая копия, не `push` и не `count++`.
- Апдейтер, если новое зависит от старого.
- Пропсы не клонируют в state без причины; длины и суммы считают.
- Общее наверх, частное оставить карточке.
