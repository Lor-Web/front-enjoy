Самая дорогая ошибка в начале — обращаться с React как с jQuery. Библиотека не «помогает найти элемент», она просит описать экран целиком.

## Не лезьте в DOM «чтобы побыстрее»

`document.querySelector`, `innerHTML`, ручной `classList` внутри компонента почти всегда обходят модель «данные → разметка». На короткой дистанции счётчик заказа обновится. На длинной React перерисует кусок и затрёт вашу правку — или наоборот, вы затрёте то, что он только что поставил.

Исключения редки: фокус на поле, измерение ширины, интеграция с картой. Даже там сначала ищут ref и эффект, не селектор по классу из CSS.

Пока вы в уроках «Зёрнышка» — **ноль** прямых обращений к DOM, кроме `createRoot` в `main.jsx`.

## Один источник правды

Число позиций в заказе живёт в одном месте. Шапка, `OrderBar` и кнопка не хранят свои копии «на всякий случай».

Дубли данных — классика: в карточке `inStock: false`, а кнопка всё равно активна, потому что смотрит на другое поле. Сначала спроектируйте объект напитка, потом экран.

## Не тащите состояние мира на втором уроке

Redux, Zustand, React Query не нужны, чтобы нарисовать шапку кафе. Сначала пропсы и `useState`. Глобальное хранилище появляется, когда одно и то же состояние реально делят далёкие ветки дерева и пропсы уже неудобны.

Вакансии это плохо объясняют: «мы на Redux» часто значит «приложение большое», а не «с Redux надо начинать».

## Не оборачивайте каждый абзац

Компонент — граница смысла, не способ «сделать по-взрослому». `LattePriceInRublesOnTheCard` ради одной строки цены — шум.

Делите, когда:

- кусок переиспользуется (`DrinkCard`);
- у куска своё имя в голове (`Header`, `OrderBar`);
- файл перестал читаться сверху вниз.

Иначе `CafeApp` из трёх вызовов честнее, чем дерево из двадцати пустых обёрток.

## Фреймворк — отдельное решение

Next / Remix берут, когда нужен сервер, маршруты файлами, SSR. Для портфолио-меню на Vite этого нет.

Признак, что фреймворк выбрали рано: вы не можете показать, где в проекте `createRoot`, и путаете `page.tsx` с компонентом React.

## Не учитесь по классовым туториалам 2018

`class CafeApp extends React.Component` ещё живёт в легаси. Новый код кафе пишут функциями. Если статья начинается с `this.state` и не упоминает хуки — это история, не рабочий стандарт 19-й версии.

## Читайте первоисточник точечно

react.dev полезен как спецификация поведения, не как текст для копирования. Когда в уроке написано «данные → разметка», а в чате советуют `forceUpdate` — верьте модели, не трюку.

## Что запомнить

- React не jQuery: не патчите DOM руками.
- Данные в одном месте, экран — проекция.
- Сначала компоненты и состояние, потом библиотеки «для взрослых».
- Vite, пока задача — библиотека; фреймворк — когда появился сервер.
