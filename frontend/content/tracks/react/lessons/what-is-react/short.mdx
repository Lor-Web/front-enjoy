В прошлом уроке проект уже запускается локально. Дальше весь трек мы собираем одно мини-приложение: меню кафе **«Зёрнышко»**. Сначала это будет шапка и одна карточка напитка. К концу трека — список из данных, бейджи «хит» и «нет в наличии», кнопка «В заказ» и общий счётчик. Каждый урок добавляет кусок к этой картине.

## Что такое React

React — **библиотека** для интерфейсов. Не целый фреймворк: он не диктует, как ходить на сервер или как устроен роутинг. Его задача — помочь описать экран кусками и обновлять его, когда меняются данные.

Кусок экрана в React называют **компонентом**. Шапка, карточка латте, кнопка «В заказ» — это отдельные функции, которые возвращают разметку. Страница кафе — дерево таких функций.

```jsx
createRoot(document.getElementById("root")).render(<CafeApp />);
```

Эта строка говорит: «нарисуй приложение внутри `#root`». Всё остальное — уже наши компоненты.

## Зачем он нужен

Без библиотеки экран собирают руками: найти элемент, поменять текст, повесить клик, не забыть соседнюю кнопку. Когда данных много, легко рассинхронизировать «что в переменной» и «что на экране».

React переворачивает подход. Вы описываете, **как экран должен выглядеть при текущих данных**. Нажал «В заказ» — изменилось число — React заново вызывает компоненты и рисует новое описание. Вам не нужно вручную править DOM в десяти местах.

Пока запомните одну мысль: **данные → разметка**. Кнопка не «дописывает HTML», она меняет данные. Экран подстраивается сам.

## Что мы построим

К концу трека `CafeApp` будет выглядеть примерно так:

```jsx
function CafeApp() {
  return (
    <>
      <Header />
      <Menu />
      <OrderBar />
    </>
  );
}
```

- `Header` — название кафе.
- `Menu` — список напитков из массива.
- `OrderBar` — сколько позиций уже в заказе.

По пути появится карточка `DrinkCard`: имя, цена, бейджи, кнопка. Сегодня достаточно понять роль React и увидеть точку входа. В следующем уроке соберём каркас из компонентов.

## Что запомнить

- React описывает интерфейс функциями-компонентами.
- Это библиотека для UI, а не «весь бэкенд в одной коробке».
- Мы меняем данные — экран пересобирается из описания.
- Учебный проект трека — меню кафе «Зёрнышко».
