Чтобы собирать меню кафе **«Зёрнышко»** не только в голове, его нужно запустить у себя на компьютере. React — это библиотека в JavaScript-проекте: её подключают через сборщик. Сегодня стандартный путь — [Vite](https://vite.dev/) и шаблон React.

## Что понадобится

Нужен **Node.js** текущей LTS-версии. Вместе с ним ставится `npm` — программа, которая скачивает пакеты.

В терминале проверьте, что установка прошла:

```bash
node -v
npm -v
```

Должны появиться номера версий, например `v22.x` и `10.x`. Если команда «не найдена» — скачайте Node.js с официального сайта и откройте терминал заново.

Дальше можно пользоваться `npm`, `pnpm` или `yarn`. Ниже — `npm`: он уже есть после установки Node.

## Создаём проект

В папке, где удобно хранить код, выполните:

```bash
npm create vite@latest zernyshko -- --template react
```

`zernyshko` — имя папки. `--template react` говорит Vite: «сразу положи React и JSX». Для TypeScript был бы шаблон `react-ts`; в этом треке пишем на JSX, без типов.

Перейдите в проект и поставьте зависимости:

```bash
cd zernyshko
npm install
```

`node_modules` — скачанные библиотеки, в том числе `react` и `react-dom`. Эту папку в git не коммитят.

## Запускаем

```bash
npm run dev
```

Vite поднимет локальный сервер и напишет адрес вроде `http://localhost:5173`. Откройте его в браузере: должна появиться стартовая страница шаблона. Сохраняете файл в `src` — экран обновляется сам.

Остановить сервер: `Ctrl+C` в том же терминале.

## Где живёт React

Три файла важны с первого дня.

`index.html` — обычная страница. Внутри неё пустой контейнер:

```html
<div id="root"></div>
```

`src/main.jsx` — вход. Он говорит React, куда рисовать приложение:

```jsx
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import App from "./App.jsx";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <App />
  </StrictMode>,
);
```

`createRoot(...).render(<App />)` монтирует корневой компонент в `#root`. `StrictMode` в разработке подсвечивает ошибки; на то, что вы видите на экране, он почти не влияет.

`src/App.jsx` — пока заготовка Vite. Её мы постепенно заменим на `CafeApp`: шапка, меню, заказ.

Откройте `App.jsx`, поменяйте любой текст, сохраните — браузер должен показать новое. Если это сработало, окружение готово. Дальше разберёмся, зачем React вообще нужен и как из функций собрать кафе.

## Что запомнить

- React запускают не «открытием HTML», а через Node.js и сборщик.
- Проект создают шаблоном Vite: `npm create vite@latest … -- --template react`.
- `npm install` ставит пакеты, `npm run dev` включает локальный сервер.
- Вход: `createRoot` рисует `<App />` в `#root`.
