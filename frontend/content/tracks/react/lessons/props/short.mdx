Карточка умеет показать латте, но эспрессо ей неоткуда взять: имя и цена зашиты внутри. **Пропсы** — это аргументы компонента. Родитель передаёт данные, дочерний компонент их рисует.

## Передаём как атрибуты

В JSX пропсы выглядят как HTML-атрибуты. Строку можно в кавычках, всё остальное — в фигурных скобках.

```jsx
function Menu() {
  return (
    <section>
      <h2>Меню</h2>
      <DrinkCard name="Латте" price={280} />
      <DrinkCard name="Эспрессо" price={180} />
    </section>
  );
}
```

Один и тот же `DrinkCard` — две разные карточки. Меняется не функция, а входные данные.

## Читаем пропсы

Аргумент функции компонентов — объект. Имена полей совпадают с теми, что вы написали в теге.

```jsx
function DrinkCard(props) {
  return (
    <article className="card">
      <h3 className="card-title">{props.name}</h3>
      <p className="card-price">{props.price} ₽</p>
    </article>
  );
}
```

Чаще поля сразу разбирают:

```jsx
function DrinkCard({ name, price }) {
  return (
    <article className="card">
      <h3 className="card-title">{name}</h3>
      <p className="card-price">{price} ₽</p>
    </article>
  );
}
```

Это тот же объект, только без повторения `props.`.

## Данные живут снаружи

Объект напитка можно собрать в `Menu` и раздать полями — или передать целиком. Пока достаточно полей: так проще видеть, что именно нужно карточке.

```jsx
function Menu() {
  const latte = { name: "Латте", price: 280 };
  const espresso = { name: "Эспрессо", price: 180 };

  return (
    <section>
      <h2>Меню</h2>
      <DrinkCard name={latte.name} price={latte.price} />
      <DrinkCard name={espresso.name} price={espresso.price} />
    </section>
  );
}
```

Пропсы **только для чтения**. Карточка не делает `price = price + 10`. Если цена должна измениться, меняют данные у родителя — и передают новое значение. К изменению данных мы вернёмся в уроке про состояние.

`CafeApp` по-прежнему только раскладывает экран:

```jsx
function CafeApp() {
  return (
    <div>
      <Header />
      <Menu />
    </div>
  );
}
```

Меню знает список напитков, карточка — как нарисовать один. Ответственность разделена.

## Что запомнить

- Пропсы — входные данные компонента, как аргументы функции.
- Передают в теге: `name="Латте"` или `price={280}`.
- Читают из объекта или через `{ name, price }`.
- Дочерний компонент пропсы не меняет — он их показывает.
